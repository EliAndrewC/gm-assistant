# Implementation Plan: The placer tests the footprint it draws

**Branch**: none - `SPECIFY_FEATURE=121-placer-drawn-footprint` | **Date**: 2026-08-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/121-placer-drawn-footprint/spec.md`

## Summary

Two placement defects, fixed in one pool re-roll, in a fixed order:

1. **Item 3 first.** The homestead bundle path is seated from `_bundle_geom`'s rects and never reaches `_fits`, so it never gets the footprint-vs-tread test that `_fits` gained on 2026-08-12; `_rect_blocked` ends at `self._near_corridor(cx, cy)`, a bare center test. Give the bundle path the same drawn-footprint treatment against drawn surfaces.
2. **Item 2 second.** Replace the collision VERDICT in `_fits` - currently half-diagonal circles against `placed` and `grove_rects` - with `sat_overlap` on real rotated corner quads, while `_reach_index` keeps its circumscribed reach box as a PREFILTER. Second because rotation-invariance is what the circle has been supplying: an earlier naive swap produced two genuine overlaps on a map with 90/180-degree buildings.
3. **Then re-derive the constants** that exist to absorb these defects, from the grounding in `research.md` rather than by tuning until green.

The ordering is not a preference; it is the documented diagnosis. Doing item 2 first converts a measured inefficiency into shipped overlaps.

## Technical Context

**Language/Version**: Python 3.14 (container pin)

**Primary Dependencies**: none new. `sat_overlap` and `edge_gap` already exist in `l7r/diagram/settlement/_geom/`; `PointGrid` / `indexed_grid` already back `_reach_index`.

**Storage**: pool manifests (`pool/*/*.json`), regenerated by their `.gen.py`

**Testing**: pytest (`-n auto`), the `check_village/` gate (~189 checks/hamlet), the 24-seed `cohort_audit`, and `make done` (ruff + ruff format + mypy --strict + pytest + coverage floor)

**Target Platform**: Linux container, offline

**Project Type**: generator library + validator (no UI)

**Performance Goals**: no regression in per-map generation time. `sat_overlap` runs only on candidates the prefilter admits, so the exact test executes on a small fraction of pairs; the prefilter itself is unchanged. Watch the two heaviest scripted maps (Sawada ~20 s, Kashikawa ~16 s) - a >5% whole-process slowdown is a finding, not noise.

**Constraints**: no frozen legacy map may regenerate; no new regressions (Principle XIII); `_reach_index`'s reach box must remain >= the exact test's reach or the index starts deciding.

**Scale/Scope**: 2 placement modules (`settlement/houses.py`, `settlement/rolling/fit.py`), 1 constants module (`hamletgen/consts.py`), 4 live scripted hamlets to re-roll, 4 settlement reviews.

## Risks

| Risk | Why it is real | Mitigation |
|---|---|---|
| The tightened verdict refuses a sanctioned abutment | Groves may hug a paddy bund and adjacent groves abut into one shared windbreak; a naive exact test forbids both | The abutment tolerance is preserved explicitly and gets its own ratchet entry, not just a passing cohort |
| The exact test is applied to a soft clearance | Caption bands, civic aprons and fence standoffs are slack a footprint routinely overhangs; tightening them once cost a well and moved a punishment ground | Surfaces get the footprint test; clearances keep center treatment. Stated in a comment at the point of the test (FR-003) |
| The prefilter is tightened along with the verdict | If the reach box shrinks below the exact test's reach, the index starts deciding instead of pruning, and pairs are rejected before the exact test runs | `contracts/placement.md` pins the invariant; the existing prefilter ratchet covers it |
| Re-derivation becomes tuning-until-green | The tempting move is to lower a constant until the cohort passes, which launders a defect into a number | Each new value is derived in `research.md` from stated geometry and history FIRST, then tested. A value that needs tuning to pass is a finding about the fix, not about the constant |
| More legal seats change more than houses | Packing changes cascade into wells, gardens, groves and windbreaks | Every moved map gets a full `settlement-review`, not a houses-only spot check |
