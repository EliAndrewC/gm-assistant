# `l7r.money` - the `/money` skill's arithmetic and data, and the Money section (features 219, 222, 223)

The skill itself is `.claude/skills/money/SKILL.md`; spec and decisions in `specs/219-money-skill/` and
`specs/222-money-basket-and-section/` (the standard basket's research and 2026 prices are in its `research.md`), and
`specs/223-koku-index-reading/` (goods dollars as an index: two readings, a range, eras averaged in rice). The
toolkit's Money section is `/money` (landing), `/money/koku` (the playground) and `/money/prices` (the price sheets).

| file | holds |
|---|---|
| `coins.py` | Exact coin arithmetic in whole sen: `parse`, `fmt`, `everyday` (the two largest coins, rounded). |
| `readings.py` | The koku's rice mass, the US wage readings (wage dollars), `laborer_days`. |
| `basket.py` | Baskets, dated dollar snapshots (with substitutes), eras priced in silver; Rokugan's prices (each good's price in rice, averaged over the eras), the single-good kokus, the two readings (whole basket, average over goods) and era conversion. The why (anchor, means, borrowed prices, housing) is in its docstring. |
| `conversions.py` | The conversion table diagram's site reads (`data/conversions.json`, GENERATED by `export`). |
| `bls.py` | BLS average prices via FRED: fills series-tied options on `reprice`, and `crosscheck`. |
| `prices.py` | The price sheets (`/money/prices`, feature 225): the ledger's Rokugani prices grouped by kind, first matching tag wins; a shrine-builder line (tagged both `construction` and `shrine`) stays on the shrine builder. A new tag no sheet takes fails `test_every_eligible_row_is_on_exactly_one_sheet`: add it to a sheet in `SHEETS`. |
| `web.py` | The playground's link state, rows and embedded data; `../static/js/money.js` is its browser twin (`compute`). |
| `ledger.py` | Load, validate and search the price ledger; the row rules are in its docstring. |
| `rules.py` | Consistency rules between synthesis rows (`data/rules.jsonl`): a kimono costs at least its cloth. |
| `calibration.py` | The estimate log, request links and findings (feature 220), and the calibration measures. |
| `__main__.py` | The command line the skill runs (`convert`, `dollars`, `price`, `history`, `baskets`, `era`, `reprice`, `crosscheck`, `export`, `check`, and the estimate log's commands). |
| `data/goods.json` | Every good a basket may hold: name, unit, why. |
| `data/baskets/<id>.json` | What a basket holds, per adult per year. `standard` is the default; `complete: true` marks a whole household year, the only kind the whole-basket reading uses. Since feature 224 its soybeans are split into miso (39 kg), soy sauce (13.8 L) and whole beans (34.4 kg), the basis in `goods.json` and the basket's description. |
| `data/era-weights.json` | Each era's weight in Rokugan's prices; an era not named weighs 1 (provisional until the GM weighs them). |
| `data/snapshots/YYYY-MM[-DD].json` | One dated dollar pricing each, ordered by `date` (not file name); the first option per good is the default. **Never edit an old one**; `reprice` starts the next. |
| `data/eras/<id>.json` | Coins, goods and a day's wage in grams of pure silver at one place and time; `kyoto-1745` is the reference (its rice anchors Rokugan's coin), at the Genbun monme. A price with `borrowed` (another era's ratio, or set equal to a good) is left out of the cross-era mean unless nothing else prices the good. A price with `excluded` (the GM's ruling that it is not pre-modern: Tokyo 1882's linen and kerosene) is left out always. WRITTEN by `specs/222-money-basket-and-section/measure/eras.py` from diagram#13's figures: edit the script, run it, then `export`. |
| `data/conversions.json` | Generated; regenerate with `export` after any change to the above. |
| `data/wages.json` | Dated US unskilled wages for the wage-dollar reading; newest is the default. |
| `data/ledger.jsonl` | The price ledger, one row per line, figures in sen. Rows with an `id` are synthesis rows; `shrine/...` rows price the shrine builder (feature 216). |
| `data/rules.jsonl` | Consistency rules. |
| `data/swings.jsonl` | One note per class of good: steady, swung or sticky across periods, and why (diagram#15). `price` prints the first class sharing a row's tag, so a specific class precedes `food`. |
| `data/estimates.jsonl` | Logged guesses. **Append only**: a test fails if a committed line changes. |
| `data/requests.jsonl`, `data/findings.jsonl` | Estimate -> diagram issue; what the research showed. |

## Testing

```
( cd webapp && python3 -m pytest -n auto tests/test_money.py tests/test_money_basket.py tests/test_money_calibration.py tests/test_money_routes.py tests/test_money_js.py )
( cd webapp && python3 -m l7r.money check && python3 -m l7r.money calibration && python3 -m l7r.money estimates --open )
```

`test_2017_snapshot_reproduces_the_spreadsheet` pins the 2017 basket to the shared sheet ($797.22 = 144.32 zeni ->
$552 per koku, by Kyoto 1745-54 alone and the arithmetic mean); if it fails, an old snapshot was edited.
`test_reference_only_weights_reproduce_feature_222s_prices` pins the era averaging to Kyoto's own prices at Kyoto-only
weights. `test_committed_table_is_current` fails when `conversions.json`
is stale (run `export`). `test_browser_and_server_agree` runs `money.js` under node against `basket.reading`.

The page by hand: `PORT=8097 cherryd --import l7r.app` from the clone's `webapp/`, open `/money/koku`. Switch Housing
off: the averaged figure moves and the whole-basket figure does not. Pick Calrose rice: both move. Choose the
arithmetic mean with every good on: the two figures match. Open "Which periods set Rokugan's prices", set Kyoto
1745-54's weight to 0: fish's detail now rests on Beijing 1615, Beijing 1820, Canton and Tokyo only. The address bar carries each change and
reloading it reproduces the figures. Screenshots: the `money*` entries in `tests/screenshot.py`.

`test_every_ledger_row_carries_label_and_source` loads the real ledger, so a row without a label or source fails the
gate.
